# Project Title

Project Title: Bikeshare

The project outputs statistics coming from a bike shop from three different cities (chicago, new york city and washington).
With that it is possible to get information of the most common time and duration where the bikes are used. 

## Information about how to use your project

Execute the project by using:

python bikeshare_2.py
